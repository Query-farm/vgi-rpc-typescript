All public symbols are exported from the `vgi-rpc` package entry point.

## Classes

### Protocol

Fluent builder for defining RPC methods.

```typescript
import { Protocol } from "@query-farm/vgi-rpc";

const protocol = new Protocol(name: string, options?: { protocolVersion?: string });
```

**Properties:**
- `name: string` — the protocol/service name
- `protocolVersion: string` — application protocol surface version (canonical semver `MAJOR.MINOR.PATCH`), or `""` when unset
- `protocolVersionParts: readonly [number, number, number] | null` — parsed semver tuple, `null` when unset

**Methods:**
- `unary(name, config)` — register a [unary method](/guides/unary-methods/)
- `producer<S>(name, config)` — register a [producer stream](/guides/producer-streams/)
- `exchange<S>(name, config)` — register an [exchange stream](/guides/exchange-streams/)
- `getMethods()` — returns `Map<string, MethodDefinition>`

### VgiRpcServer

RPC server that reads Arrow IPC requests from stdin and writes responses to stdout.

```typescript
import { VgiRpcServer } from "@query-farm/vgi-rpc";

const server = new VgiRpcServer(protocol, options?);
```

**Options:**
- `enableDescribe?: boolean` — register the `__describe__` introspection method (default: `true`)
- `serverId?: string` — server ID included in response metadata (random if omitted)
- `protocolVersion?: string` — operator-supplied protocol-contract version label surfaced to dispatch hooks
- `dispatchHook?: DispatchHook` — observability hook fired around each dispatch (e.g. `AccessLogHook`)
- `externalLocation?: ExternalLocationConfig` — external-storage config for large-batch externalisation
- `onServeStart?: ServeStartHook` — lifecycle hook fired once before the first dispatched request

**Methods:**
- `run(): Promise<void>` — start the server loop; reads requests until stdin closes

### AuthContext

Authentication context available to RPC handlers (via `ctx.auth`) and produced by the authentication factories.

```typescript
import { AuthContext } from "@query-farm/vgi-rpc";

const ctx = new AuthContext(
  domain: string,
  authenticated: boolean,
  principal: string | null,
  claims?: Record<string, any>,
);
```

**Properties:**
- `domain: string` — authentication domain (e.g. `"jwt"`, `"mtls"`)
- `authenticated: boolean` — whether the request was authenticated
- `principal: string | null` — authenticated principal
- `claims: Record<string, any>` — additional claims

**Methods:**
- `static anonymous(): AuthContext` — create an unauthenticated (anonymous) context
- `requireAuthenticated(): void` — throw an `RpcError` if not authenticated

### OutputCollector

Accumulates output batches during produce/exchange calls. Passed as the `out` parameter to streaming handlers.

```typescript
import { OutputCollector } from "@query-farm/vgi-rpc";
```

**Methods:**
- `emit(columns: Record<string, any[]>)` — emit a data batch from column arrays
- `emit(batch: RecordBatch, metadata?: Map<string, string>)` — emit a pre-built RecordBatch
- `emitRow(values: Record<string, any>)` — emit a single-row batch
- `finish()` — signal stream completion (producer only)
- `clientLog(level, message, extra?)` — emit a log message

**Properties:**
- `finished: boolean` — whether `finish()` has been called
- `batches: EmittedBatch[]` — accumulated batches
- `outputSchema: Schema` — the output schema

### AccessLogHook

`DispatchHook` implementation that emits one JSONL access-log record per RPC dispatch. Install via `new VgiRpcServer(protocol, { dispatchHook })`. The record shape conforms to the vgi-rpc access-log specification and validates under `vgi-rpc-test --access-log`.

```typescript
import { AccessLogHook, FdSink } from "@query-farm/vgi-rpc";

const hook = new AccessLogHook(
  sink: AccessLogSink,
  options?: AccessLogOptions | string,
);
```

`options` may be an `AccessLogOptions` object or a bare server-version string (legacy form). At the default `"INFO"` level the heavy `request_data` field is replaced with a `truncated: true` marker plus `original_request_bytes`; pass `level: "DEBUG"` to capture full payloads.

**`AccessLogOptions`:**
- `serverVersion?: string` — server version string
- `level?: "INFO" | "DEBUG"` — verbosity for heavy fields (default: `"INFO"`)

### FdSink

`AccessLogSink` backed by a file descriptor; uses synchronous writes for ordering. Requires Node.js or Bun (`node:fs.writeSync`).

```typescript
import { FdSink } from "@query-farm/vgi-rpc";

const sink = new FdSink(fd: number);
```

## External storage

Helpers for offloading large Arrow IPC batches to pluggable storage. When a batch exceeds a configurable threshold it is serialized to IPC, optionally zstd-compressed, and uploaded; the batch is replaced with a zero-row "pointer batch" carrying the download URL and SHA-256 checksum in metadata. Wire up via the `externalLocation` server / handler option.

### httpsOnlyValidator

Default URL validator that rejects non-HTTPS URLs. Throws on rejection.

```typescript
import { httpsOnlyValidator } from "@query-farm/vgi-rpc";

httpsOnlyValidator(url: string): void;
```

### isExternalLocationBatch

Returns `true` if the batch is a zero-row pointer to external data.

```typescript
import { isExternalLocationBatch } from "@query-farm/vgi-rpc";

isExternalLocationBatch(batch: RecordBatch): boolean;
```

### makeExternalLocationBatch

Create a zero-row pointer batch with a location URL and optional SHA-256.

```typescript
import { makeExternalLocationBatch } from "@query-farm/vgi-rpc";

makeExternalLocationBatch(schema: Schema, url: string, sha256?: string): RecordBatch;
```

### maybeExternalizeBatch

Externalize a batch if it exceeds the threshold; otherwise returns it unchanged.

```typescript
import { maybeExternalizeBatch } from "@query-farm/vgi-rpc";

await maybeExternalizeBatch(batch: RecordBatch, config?: ExternalLocationConfig | null);
// Returns: Promise<RecordBatch>
```

### resolveExternalLocation

Resolve an external pointer batch by fetching the data from its URL (validating, decompressing, and verifying the checksum). Returns the original batch when it is not a pointer or no config is supplied.

```typescript
import { resolveExternalLocation } from "@query-farm/vgi-rpc";

await resolveExternalLocation(batch: RecordBatch, config?: ExternalLocationConfig | null);
// Returns: Promise<RecordBatch>
```

## Authentication factories

Built-in factories for creating `AuthenticateFn` callbacks. Pass the result to `createHttpHandler(protocol, { authenticate })`.

See [HTTP Transport — Authentication](/guides/http-transport/#authentication) for usage examples.

### jwtAuthenticate

Create a JWT-validating authenticate callback using `oauth4webapi`.

```typescript
import { jwtAuthenticate } from "@query-farm/vgi-rpc";

const auth = jwtAuthenticate({
  issuer: "https://auth.example.com",
  audience: "https://api.example.com/vgi",
});
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `issuer` | `string` | required | Expected `iss` claim (used for OIDC discovery) |
| `audience` | `string` | required | Expected `aud` claim |
| `jwksUri` | `string` | `undefined` | Explicit JWKS URL (discovered from issuer if omitted) |
| `principalClaim` | `string` | `"sub"` | JWT claim to use as `AuthContext.principal` |
| `domain` | `string` | `"jwt"` | `AuthContext.domain` value |

### bearerAuthenticate

Create a bearer-token authenticate callback with a custom validate function.

```typescript
import { bearerAuthenticate } from "@query-farm/vgi-rpc";

const auth = bearerAuthenticate({
  validate: (token: string) => { /* return AuthContext or throw */ },
});
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `validate` | `BearerValidateFn` | Receives the raw token, returns `AuthContext` on success, throws on failure |

### bearerAuthenticateStatic

Create a bearer-token authenticate callback from a static token map. Uses constant-time comparison for token lookup.

```typescript
import { bearerAuthenticateStatic } from "@query-farm/vgi-rpc";

const auth = bearerAuthenticateStatic({
  tokens: { "key-abc": aliceContext, "key-def": bobContext },
});
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `tokens` | `Record<string, AuthContext> \| ReadonlyMap<string, AuthContext>` | Maps bearer token strings to `AuthContext` values |

### chainAuthenticate

Chain multiple authenticate callbacks, trying each in order.

```typescript
import { chainAuthenticate } from "@query-farm/vgi-rpc";

const auth = chainAuthenticate(jwtAuth, apiKeyAuth);
```

| Behaviour | Exception type | Result |
|-----------|----------------|--------|
| Credentials accepted | *(none)* | Returns `AuthContext`, stops chain |
| Bad / missing credentials | Plain `Error` (`constructor === Error`) | Tries next authenticator |
| Authenticated but forbidden | `Error` with `name === "PermissionError"` | Propagates immediately |
| Bug in authenticator | `TypeError`, `RangeError`, etc. | Propagates immediately |
| Non-Error throw | any | Propagates immediately |

Throws at construction time if called with no authenticators.

### mtlsAuthenticate

Create an mTLS authenticate callback with custom certificate validation. Parses a URL-encoded PEM from the specified header.

```typescript
import { mtlsAuthenticate } from "@query-farm/vgi-rpc";

const auth = mtlsAuthenticate({
  validate: (cert) => new AuthContext("mtls", true, "principal", {}),
  header: "X-SSL-Client-Cert",
  checkExpiry: false,
});
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `validate` | `CertValidateFn` | required | Receives `X509Certificate`, returns `AuthContext` or throws |
| `header` | `string` | `"X-SSL-Client-Cert"` | Header containing URL-encoded PEM |
| `checkExpiry` | `boolean` | `false` | Check validity period before calling validate |

### mtlsAuthenticateFingerprint

Create an mTLS authenticate callback using certificate fingerprint lookup. Fingerprints must be lowercase hex without colons.

```typescript
import { mtlsAuthenticateFingerprint } from "@query-farm/vgi-rpc";

const auth = mtlsAuthenticateFingerprint({
  fingerprints: { "a1b2c3...": new AuthContext("mtls", true, "service-a") },
});
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `fingerprints` | `Record<string, AuthContext> \| ReadonlyMap<string, AuthContext>` | required | Fingerprint-to-context map |
| `header` | `string` | `"X-SSL-Client-Cert"` | Header containing URL-encoded PEM |
| `algorithm` | `string` | `"sha256"` | Hash algorithm (`sha256`, `sha1`, `sha384`, `sha512`) |
| `checkExpiry` | `boolean` | `false` | Reject expired certificates |

### mtlsAuthenticateSubject

Create an mTLS authenticate callback using certificate subject CN. Populates claims with `subject_dn`, `serial`, and `not_valid_after`.

```typescript
import { mtlsAuthenticateSubject } from "@query-farm/vgi-rpc";

const auth = mtlsAuthenticateSubject({
  allowedSubjects: new Set(["my-service"]),
});
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `header` | `string` | `"X-SSL-Client-Cert"` | Header containing URL-encoded PEM |
| `domain` | `string` | `"mtls"` | `AuthContext.domain` value |
| `allowedSubjects` | `ReadonlySet<string> \| null` | `null` | Restrict accepted CNs |
| `checkExpiry` | `boolean` | `false` | Reject expired certificates |

### mtlsAuthenticateXfcc

Create an authenticate callback from the Envoy `x-forwarded-client-cert` header. No crypto dependencies required.

```typescript
import { mtlsAuthenticateXfcc } from "@query-farm/vgi-rpc";

const auth = mtlsAuthenticateXfcc({ selectElement: "first" });
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `validate` | `XfccValidateFn` | — | Custom validation (default: extract CN from Subject) |
| `domain` | `string` | `"mtls"` | `AuthContext.domain` value |
| `selectElement` | `"first" \| "last"` | `"first"` | Which element to use when multiple are present |

### MethodInfo

```typescript
interface MethodInfo {
  name: string;
  type: "unary" | "stream";
  paramsSchema: Schema;
  resultSchema: Schema;
  inputSchema?: Schema;
  outputSchema?: Schema;
  headerSchema?: Schema;
  doc?: string;
  paramTypes?: Record<string, string>;
  defaults?: Record<string, any>;
}
```

:::note
`doc`, `paramTypes`, and `defaults` are not carried on the wire under the slim
DESCRIBE v4 schema, so they are `undefined` at runtime when parsed from a
`__describe__` response. The `Protocol` class is the source of truth for
human-readable type info — read these fields from the local `Protocol`
definition rather than from a remote `MethodInfo`.
:::

### DispatchHook

Observability hook called around RPC dispatch. Implementations must be safe for concurrent use (the HTTP transport is concurrent). `AccessLogHook` implements this interface.

```typescript
interface DispatchHook {
  onDispatchStart(info: DispatchInfo): HookToken;
  onDispatchEnd(token: HookToken, info: DispatchInfo, stats: CallStatistics, error?: Error): void;
}
```
